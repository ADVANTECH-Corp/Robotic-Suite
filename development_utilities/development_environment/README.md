# Development Environment

This section provides pre-configured environments for robotics development.

- **[ISAAC ROS](./isaac_ros/)** – Containerized environment for GPU-accelerated perception  
- **[QIR ROS SDK](./qir_ros/)** – Containerized environment for QIR ROS SDK development and Qualcomm-accelerated robotics workloads  
- **[Autoware](./autoware/)** – Containerized stack for autonomous driving workflows  

These environments are designed to reduce setup effort and accelerate development.
